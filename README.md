# Smart Agri Assistant (مساعد المزارع الذكي)

نظام متكامل ومفتوح المصدر لمساعدة المزارعين في مصر والوطن العربي على:
1. **تشخيص أمراض النباتات بالذكاء الاصطناعي:** رفع صورة لورقة نبات للحصول على التشخيص الدقيق، نسبة التأكد، وأفضل 3 احتمالات، مع الصراحة التامة في حال عدم التأكد أو في حال عدم كون الصورة ورقة نبات مدعومة.
2. **إرشادات وقائية ومكافحة موثقة:** نصائح عملية ومواد فعالة مرخصة وموثقة رسمياً من وزارة الزراعة والجهات البحثية المعتمدة.
3. **مستشار التربة والري:** تحديد المحاصيل الأنسب للزراعة بناءً على خصائص التربة ومعدلات التغذية والمناخ في البيئة الزراعية المصرية.
4. **حسابات وتاريخ الفحوصات:** إمكانية التسجيل وحفظ سجل التشخيصات وتحليلات التربة السابقة للمزارع بكل خصوصية وأمان.

## متطلبات التشغيل السريع (Quickstart)

### 1. المتطلبات الأساسية
- مثبت بايثون الإصدار 3.11 (Python 3.11).
- حساب Kaggle مفعل ومضاف في ملف الإعدادات للتدريب على كروت الشاشة.

### 2. التثبيت محلياً
```bash
# إنشاء البيئة الافتراضية
python -m venv .venv

# تفعيل البيئة على ويندوز
.\.venv\Scripts\Activate.ps1

# تثبيت المتطلبات
pip install -r requirements.txt
```

### 3. إعداد متغيرات البيئة
انسخ ملف `.env.example` إلى `.env`:
```bash
cp .env.example .env
```
